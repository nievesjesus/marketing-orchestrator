# Font licenses

All bundled fonts are licensed under the SIL Open Font License 1.1 (OFL). Each family's license text
sits next to this file as `<Family>-OFL.txt`.

`InstrumentSerif-OFL.txt` was assembled for this repository: the OFL 1.1 body is identical for every
OFL family, and the copyright line is the one embedded in `InstrumentSerif-Regular.ttf` (name table, ID 0).
The upstream pack the other files came from did not include a separate license file for Instrument Serif.
